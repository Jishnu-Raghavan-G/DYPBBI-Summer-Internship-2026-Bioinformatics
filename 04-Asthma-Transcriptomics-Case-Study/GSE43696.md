Overview

GSE43696 is the GEO dataset used as the main dataset for the asthma transcriptomics case study during the internship.

The purpose of using this dataset was to understand how publicly available gene-expression data can be compared between healthy and asthma samples and then taken through a series of downstream bioinformatics analyses.

GEO Accession
Dataset: GSE43696
Database: NCBI Gene Expression Omnibus (GEO)
Study type: Gene-expression / transcriptomics dataset
Disease context: Asthma

The accession number GSE43696 is the identifier used to locate the dataset within GEO.

Why GEO Was Used

The Gene Expression Omnibus (GEO) is a public repository containing gene-expression and other functional genomics datasets.

Using a public dataset makes it possible to study an existing biological experiment computationally without having to generate the expression data experimentally.

In this case, the dataset provided the basis for investigating gene-expression differences associated with asthma.

Biological Comparison

The case study involved comparing:

   ↓
      Gene-expression patterns

The comparison was used to identify genes showing differences in expression between the two conditions.

GEO2R

GEO2R was used to compare the expression profiles of the selected sample groups.

The basic idea was:

Select dataset
      ↓
Define sample groups
      ↓
Compare expression
      ↓
Obtain statistical results
      ↓
Identify differentially expressed genes

GEO2R therefore provided a convenient starting point for the differential-expression portion of the case study.

The detailed GEO2R procedure is documented separately in:

GEO2R-Analysis.md
Differentially Expressed Genes

Following the group comparison, genes were examined according to their expression differences and statistical significance.

Important measures considered during the workflow included:

Fold change
log2 fold change
p-value
Adjusted p-value
Statistical significance

The internship notes specifically describe filtering gene-expression results using statistical measures before selecting genes for downstream analysis.

Downstream Analysis

The selected genes from the transcriptomics analysis were subsequently investigated using several bioinformatics resources.

Functional Enrichment

Gene Ontology, KEGG and g:Profiler were used to investigate the biological functions and pathways associated with the selected genes.

Protein-Protein Interaction Analysis

STRING was used to investigate relationships between proteins associated with the analyzed genes.

Network Analysis

Cytoscape was used to visualize and explore the interaction network.

Hub-Gene Analysis

The resulting network was further examined to identify highly connected nodes that could be investigated as hub genes within the analyzed network.
