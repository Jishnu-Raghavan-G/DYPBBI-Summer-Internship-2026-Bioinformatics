# Bioinformatics Workflow

A bioinformatics workflow is a sequence of computational steps used to move from a biological question or dataset towards a meaningful biological interpretation.

During the internship, I learned how different databases and tools can be connected instead of using each one separately.

## General Workflow

```text
Biological Question
        ↓
Database / Dataset Search
        ↓
Data Collection
        ↓
Data Analysis
        ↓
Biological Interpretation
        ↓
Further Analysis
        ↓
Final Interpretation

Key Takeaway

The main thing I learned from these workflows was that bioinformatics is a connected process.

A result from one stage can become the input for the next stage:

Dataset → Genes → Functions → Pathways → Networks → Proteins → Structures → Molecular Interactions

The final interpretation still depends on both computational results and biological understanding.
